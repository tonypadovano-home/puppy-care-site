# Puppy Care — Support

Need help, found a problem, or have an idea? Email **puppypoopplanner@gmail.com** and we'll get back to you.

**Common questions**
- **How do I add someone to my household?** Family → Invite someone → Make a code, then share the code with them.
- **How do I get my data out?** Family → Export household data, or Export log for a spreadsheet (CSV).
- **How do I delete my account?** Family → Delete my account. If you're the only owner, this deletes the whole
  household for everyone — make someone else an owner first to keep it going.
